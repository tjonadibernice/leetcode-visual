# Stepwise

Visual, step-by-step walkthroughs of LeetCode solutions. Each step moves the picture (pointers, arrows, tables, trees), highlights the matching line of Python, shows the current variables, and explains in plain English why it happened.

## Problems

| Pattern | Problems |
| --- | --- |
| Arrays & two pointers | 1. Two Sum · 11. Container With Most Water · 704. Binary Search · 3. Longest Substring Without Repeating Characters |
| Linked lists & trees | 206. Reverse Linked List · 104. Maximum Depth of Binary Tree · 102. Binary Tree Level Order Traversal · 450. Delete Node in a BST |
| Dynamic programming | 70. Climbing Stairs · 322. Coin Change · 1143. Longest Common Subsequence |
| Graphs & backtracking | 200. Number of Islands · 78. Subsets |

## Run it

It's a single static file with no build step. Open `index.html` in a browser, or serve the repo with GitHub Pages.

## Controls

- ← / → step backward and forward
- Space to play or pause
- Home / End to jump to the start or end
- Edit the inputs and press **Run with this input** to try your own cases
